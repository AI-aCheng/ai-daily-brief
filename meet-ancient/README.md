# 遇见古人 — 微信小程序

> 30 道情景选择题 → 匹配 100 位古今中外古人 → 共同点 / 成败分析 / 人生启示

## 一、快速运行

### 方式 1：HBuilderX（推荐）
1. 下载安装 HBuilderX（https://www.dcloud.io/hbuilderx.html）
2. 文件 → 导入 → 从本地目录导入 → 选择本项目
3. 运行 → 运行到小程序模拟器 → 微信开发者工具（需先安装微信开发者工具并在 HBuilderX 设置里配置路径）
4. 首次会提示安装依赖，点确定

### 方式 2：命令行
```bash
npm install
npm run dev:mp-weixin      # 开发模式, 产物在 dist/dev/mp-weixin
npm run build:mp-weixin    # 生产构建, 产物在 dist/build/mp-weixin
```
然后用微信开发者工具打开产物目录（`dist/dev/mp-weixin` 或 `dist/build/mp-weixin`）。

### 微信开发者工具设置
- 导入项目时 AppID 填自己的（或选"测试号"）
- 详情 → 本地设置 → 勾选"不校验合法域名"（本地开发用）

## 三、玩法与匹配原理

- **标签体系**：39 个性格标签（冒险/谨慎/隐忍/出世/入世/谋略/乐观…）
- **答题**：每题选项带 2-3 个标签加分，30 题累加出"用户标签画像"
- **匹配**：每个古人预置 3-6 个标签画像，用**加权点积**算相似度（强标签命中权重大），取 Top3
- **结果**：主古人（共同点 3 条 / 成败分析 / 启示 3 条）+ 2 位相似古人 + 分享卡片

## 四、数据规格

| 数据 | 数量 | 说明 |
|---|---|---|
| 题目 | 30 题 | 每题 3-4 选项，覆盖职业/逆境/金钱/社交/价值观 |
| 古人 | 100 人 | 中国 70 + 外国 30，含结局类型（成功/失败/悲惨/归隐）|
| 每条古人 | 11 字段 | id/name/era/region/role/tags/outcome/summary/common/analysis/lesson |

## 五、后续扩展方向

1. **AI 解读**：接大模型 API，把用户标签画像发给 AI 生成个性化解读（当前是规则匹配 + 预设文案）
2. **云端题库**：题库/古人数据放后端，支持 A/B 测试与内容更新
3. **分享海报**：canvas 生成古人匹配卡片图（朋友圈传播）
4. **更多古人**：100 → 300+，按主题包（帝王/诗人/科学家）分批上线
5. **App 版**：uni-app 一套代码，直接云打包 Android/iOS

## 六、发布注意事项

- 小程序注册：微信公众平台（mp.weixin.qq.com）注册小程序，个人主体即可
- 类目建议："教育 > 教育信息服务" 或 "工具 > 效率"
- 上线前把 `manifest.json` 里 `mp-weixin.appid` 填成自己的
- 隐私协议：本项目无任何数据上传（纯本地），在后台填写"用户隐私保护指引"时声明不采集即可
